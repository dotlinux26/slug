# Slug — Hồ sơ kỹ thuật

Bộ tài liệu gồm bốn tệp:

- `01-PROBLEM.md` — bối cảnh, nhu cầu, phạm vi và tiêu chí đánh giá.
- `02-SOLUTION.md` — tính năng và kiến trúc sản phẩm.
- `03-AI-USAGE.md` — Stateful AI Audit, cache theo hash, quy trình recheck và quản lý ngoại lệ.

**Lưu ý:** Đây là tài liệu thiết kế đề xuất. Trước khi nộp hồ sơ, hãy đối chiếu từng tính năng với mã nguồn thực tế, đánh dấu trạng thái triển khai, bổ sung kết quả benchmark và chỉ giữ lại các tuyên bố đã có bằng chứng kiểm thử.
